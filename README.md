## 🌟 About Oerion

**Oerion** is a simple, elegant, **Python-inspired interpreted programming language** designed for beginners and creative minds.

It provides an easy-to-understand syntax for learning programming concepts while also introducing features such as **AI-powered commands**, custom file extensions, loops, variables, and a dedicated command-line interface.

Built by **[@Raja](https://github.com/luciferofx)**, Oerion aims to make programming more approachable while giving developers the freedom to experiment and build their own ideas.

## 🧠 AI-Powered Programming

Oerion includes AI-powered commands such as:

```text
ai_generate
```

Example:

```oerion
ai_generate "Write a short quote about programming"
```

This allows Oerion programs to interact with AI-powered functionality directly through the language syntax.

After installation, verify that the CLI is available:

## ▶️ How To Use

Create a file with the `.oer` extension.

Example:

```text
example.oer
```

Add your Oerion code:

```oerion
let x = 0

while x < 3:
    print x
    let x = x + 1

for i in range(5):
    print i

ai_generate "Write a short quote about programming"
```

Then run the file using:

```bash
oerion example.oer
```

## 🧪 Example Program

Here's a complete example:

```oerion
let name = "Raja"
let count = 0

print "Hello"
print name

while count < 3:
    print count
    let count = count + 1

for i in range(5):
    print i

ai_generate "Write a short quote about programming"
```

Run it with:

```bash
oerion example.oer
```
